請介紹 AIHub 的核心功能
AI
gpt-4o
AIHub 是一個多 AI 聊天介面，核心功能包括：
1. 多 AI 提供商支援
ChatGPT (GPT-4o/4o-mini)、Claude (Sonnet/Haiku/Opus)、Gemini (1.5 Pro/Flash)、Ollama 本地模型、LM Studio 本地模型
2. 端到端加密
AES-GCM + PBKDF2 (100,000 迭代)，主密碼派生，裝置指紋綁定
3. MCP 整合
支援 SSE + STDIO 雙協定，連接 filesystem、github、postgres 等工具
4. 多 AI 並行比較
Compare View 一次對比多模型回覆，選擇最佳答案
5. 智能路由
@claude /code /write 等前綴自動導向對應模型

gpt-4o
如何啟用 MCP 功能？
AI
gpt-4o
點擊右上角的 MCP 圖示 (方格圖示)，在側邊面板中：
1. 點擊「+ 新增 MCP 服務」
2. 選擇傳輸協定：SSE (遠端) 或 STDIO (本地)
3. 填入端點 URL 或命令參數
4. 點擊「測試連線」驗證
支援的工具：filesystem、github、postgres、sqlite 等
